## SUMMARY
The three enterprise ASO vendors form a clean price ladder with a structural hole at the bottom that Sniffy occupies alone. MobileAction (acquired by InMobi May 2026) starts at $15/mo with AI review/keyword analysis already included, AppTweak runs $79-549/mo plus a separate $83-833/mo reviews product, and Sensor Tower (which absorbed data.ai) is sales-only with a $74,415 median annual contract (Vendr) and $25-40k entry points for small teams. On data ground truth: AppTweak openly states its iOS keyword volume is fetched 'from Apple directly, every single day' — i.e., Apple Search Ads popularity, the same upstream source Sniffy uses — and its derived metrics (Organic Installs, Keyword Impact) only exist in ASA-supported countries, confirming there is no secret iOS volume source beyond Apple's own signal plus modeling. API access is the sharpest differentiation axis: AppTweak publishes credit-based API pricing ($166/mo floor, 250k credits, with per-datapoint prices like 10 credits for keyword volume and 500 for download estimates) and even ships an llms.txt 'for AI agents,' but still requires human credit-card signup; MobileAction's API is quote-only; Sensor Tower buries API calls inside contracts with usage caps and overage fees, and its only MCP server is an unofficial single-maintainer wrapper that needs a contract-gated token. No vendor lets an agent buy one report autonomously — the x402 niche is genuinely empty. Their real moats are panel/console-calibrated download-revenue estimates, organic-installs-per-keyword, Apple Ads impression-share history, and metadata history to 2014; nearly everything else in their keyword stack (rank, ASA volume, difficulty composites, SERP snapshots, review intelligence, CPP detection) is public-data-derivable and merely seat-licensed. The 2025-2026 AI wave splits two ways: commoditized AI analysis at $15/mo (MobileAction) versus Enterprise-gated AI visibility tracking (AppTweak's prompt-level LLM mention tracking with query fan-out), while Google's Ask Play assistant and a forthcoming official Play MCP connector make AI-mediated discovery — driven, per AppTweak, largely by ASO fundamentals — the channel to instrument cheaply before anyone else does it per-request.
